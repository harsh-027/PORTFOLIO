Harshit Srivastava – Portfolio

A modern and responsive developer portfolio built with **React**, **TypeScript**, and **Vite** to showcase my projects, skills, and experience.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- CSS
- Framer Motion

## 📦 Installation

```bash
git clone https://github.com/harsh-027/PORTFOLIO.git
cd PORTFOLIO
npm install
npm run dev
```
